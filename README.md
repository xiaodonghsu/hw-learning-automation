# HW伙伴课程自动学习扩展

1. 在 Chrome 打开 `chrome://extensions`，或在 Edge 打开 `edge://extensions`。
2. 开启开发者模式，点击「加载解压缩的扩展程序」，选择本目录。
3. 打开HW伙伴 O3 学习页面，登录并进入具体课程章节，然后点击工具栏里的「O3 课程自动学习」。再点一次可停止后续自动操作，当前视频可用网页播放器暂停。

url 前缀包括:
- https://cn.o3community.*hw*.com/cn/zh/learning

- https://e.*hw*.com/cn/talent/outPage (进入该页面可能是嵌入的shixizhi课程，请等课程加载完成后点击扩展按钮。扩展会在新标签页打开课程链接，请在新标签页继续学习。)

- https://talent.shixizhi.*hw*.com/course

# 自动化行为

点击后，扩展图标会立即显示「检查」，随后显示当前操作。将鼠标悬停在图标上可查看详细状态。课程内容已经打开，但进度栏缺失或进度无法识别时，扩展会询问是否继续。

进度高于 90% 时，扩展会先询问是否继续。每节课程会逐行滚动到底部，等待 1 秒后滚回顶部，再按页面顺序播放视频。视频播完后会自动点击「下一节」。识别到最后一节时，扩展会提示并停止。

O3 课程可能嵌入在时习知 iframe 中。扩展通过导航权限定位该 iframe，并使用时习知站点权限在课程框架中运行。升级后请在扩展管理页重新加载扩展，再刷新课程页。

如果浏览器拦截播放，可以先手动播放当前视频，再重新启动扩展。扩展仅在点击工具栏按钮时向匹配的学习页面注入脚本。
